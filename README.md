# Ritika ❤️ Shubham — Proposal Page

A romantic, GitHub Pages-ready marriage proposal page with:

- 🌻 Sunflower / warm romantic visual
- 🧸 Soft-toy theme
- 🍫 KitKat details in the hero artwork
- 💍 “Will you marry me?” question
- ✅ Animated **Yes** button → celebration + hugging animation + floating hearts
- ❌ **No** button → playful “No baby no 🥺” popup
- 📱 Responsive layout for mobile and desktop
- 🚀 No backend required — pure HTML/CSS/JavaScript

## Deploy to GitHub Pages

1. Create a new GitHub repository, e.g. `ritika-proposal`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save. GitHub will give you a public `github.io` URL.

The page is completely static, so GitHub Pages can host it directly.
